# rl-request-scheduling

Учебное распределение заявок с помощью табличного Q-learning.
Python 3.10 или новее.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

По умолчанию: 10 000 эпизодов обучения и 1 000 эпизодов оценки
для каждой из четырёх стратегий. Быстрая проверка:

```bash
python main.py --episodes 20 --eval-episodes 10 --output-dir /tmp/rl-smoke
python -m unittest discover -s tests
```

## Модель

Три оператора, максимум три заявки у каждого. Состояние — кортеж
загрузок, действие — индекс оператора. Состояние кодируется как
`16 * s[0] + 4 * s[1] + s[2]`, Q-таблица имеет размер 64 × 3.
Вероятности завершения каждой заявки за шаг: 1/2, 1/4, 1/6.
На каждом шаге поступает одна заявка, затем обрабатываются все заявки,
включая новую. При полной загрузке выбранного оператора заявка отклоняется.
Отдельной очереди ожидания нет.

Награда: `completed - 0.1 * remaining_load - rejected`.
Эпизод длится 100 шагов, затем загрузка сбрасывается. Это искусственный
лимит наблюдения непрерывной задачи: при обучении на последнем шаге
сохраняется оценка будущей награды (bootstrap). Время не входит в состояние.
`agent.update(..., done=True)` поддерживает настоящий терминальный переход
без bootstrap, если он появится в другой постановке среды.

Обучение: alpha=0.1, gamma=0.95, epsilon уменьшается после каждого эпизода
от 1.0 до 0.01 с множителем 0.995. При равных Q-значениях выбор случайный.
Настройки находятся в config.py, seed обучения — 42.

## Файлы

- src/environment.py — симуляция и StepResult.
- src/agent.py — Q-таблица, epsilon-greedy, обновление и сохранение.
- src/train.py — обучение и статистика.
- src/visualization.py — награда и скользящее среднее за 100 эпизодов.
- src/evaluate.py — оценка без обучения и исследования.
- main.py — запуск всего эксперимента.

В results/ сохраняются q_table.npy, training_history.csv,
training_reward.png, evaluation_history.csv и evaluation_summary.csv.
Повторный запуск перезаписывает результаты; для отдельного эксперимента
задайте --output-dir.

Оценка сравнивает Q-learning, случайный выбор, наименее загруженного
оператора (равенство разрешается случайно) и самого быстрого доступного.
Используется отдельный набор seed от 100000; список одинаков для стратегий,
но из-за разного числа заявок случайные траектории могут различаться.
Отчёт содержит среднюю награду и её стандартное отклонение, число
завершений и отказов, среднюю суммарную загрузку. Один запуск обучения
не доказывает превосходство алгоритма в общем случае; для устойчивых
выводов нужны повторения с разными seed обучения.
